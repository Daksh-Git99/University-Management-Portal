# University Management Portal
A university management portal built as a learning project while developing web development skills.


## 🚀 Project Goal
The goal of this project is to build one complete web application while learning:
- HTML
- CSS
- JavaScript
- Git
- GitHub
- Web deployment
The project will be developed step by step, starting with HTML and gradually adding styling and functionality.


## 📚 Current Stage
### HTML Phase
Currently learning and implementing:
- HTML document structure
- Headings and paragraphs
- Links
- Images
- Lists
- Semantic HTML
- Forms
- Tables
- Multimedia
- Accessibility
